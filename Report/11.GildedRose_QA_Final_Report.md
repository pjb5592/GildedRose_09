# Gilded Rose QA 최종 종합 보고서

작성일: 2026-05-19

## 1. 보고서 목적

본 보고서는 QA 리드 관점에서 Gilded Rose C++17 프로젝트의 **9단계 QA 워크플로(Prompt 01~09)** 및 결함 관리(10단계)를 종합 검토한 결과를 `docs/qa_final_report.md`에 정리한 내용을 기록한다.

문서화 목표는 다음과 같다.

- 테스트 완료율·gcov/lcov 커버리지를 목표치와 비교
- 결함 패턴(Severity × ItemType × 발견 단계) 분석
- 9단계 워크플로 효과·개선점 및 Best Practice 5가지 제시
- Cursor AI 활용 효과(정량·정성) 요약

### 3.4 Best Practice 5 (요약)

1. 문서 → Red 테스트 → Green 구현  
2. 경계값 매트릭스 = 테스트 SSOT  
3. 단위 테스트 + Golden Master 이중망  
4. 라인 + 브랜치 + 파일 단위 커버리지 게이트  
5. Severity × ItemType 스프린트 메트릭  

### 3.5 Cursor AI

- 정량: 단위 테스트 0→27, 통과율 0%→100%, `GildedRose.cpp` 라인 100%  
- 정성: 문서·TDD·gcov 가속 / P2·브랜치·심층 리팩토링은 명시 요청 필요
